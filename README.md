# 🛍️ ShopEasy – E-Commerce Wireframe

## 📌 Project Overview

ShopEasy is a low-fidelity e-commerce wireframe designed for an online shopping application. The project focuses on creating a simple, clear, and user-friendly shopping experience.

## 🎯 Objective

The main objective of this project is to design the basic structure and user flow of an e-commerce application before developing the final high-fidelity interface.

## 🖥️ Technologies Used

- HTML5
- CSS3
- Figma / UI-UX Design
- Visual Studio Code

## 📱 Main Screens

- 🏠 Home Page
- 🔍 Product Search
- 📦 Product Details
- 🛒 Shopping Cart
- 💳 Checkout
- ✅ Order Confirmation

## 🔄 User Flow

Home → Product Details → Add to Cart → Cart → Checkout → Order Confirmation

## ✨ Features

- Simple and clean interface
- Easy navigation
- Product browsing
- Shopping cart
- Checkout flow
- User-friendly layout
- Responsive design concept
